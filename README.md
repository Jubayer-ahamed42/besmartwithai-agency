## 🚀 How to Run Locally

### Option 1: Double Click
Simply double-click `index.html` to open it in your default web browser (Chrome, Edge, Brave).

### Option 2: Python Local Server
Run this in PowerShell inside this directory:
```bash
python -m http.server 3000
```
Then open `http://localhost:3000` in your browser.

## 🌐 One-Click Deployment

- **Vercel**: Run `vercel` or connect this folder to your GitHub repo.
- **GitHub Pages**: Upload to a repository named `besmartwithai-agency` and enable Pages from repository Settings.
- **Netlify**: Drag and drop this folder directly into the Netlify dashboard.
